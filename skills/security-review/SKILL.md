# Security review: sink tables and sources

The brief in `agents/security_reviewer.md` says how to review; this file says what to look for in a given stack and where each rule comes from. Read the sink table for the stack you detected before the generate phase; derive one from ASVS V1, V5 and V15 and the OWASP cheat sheets for a stack not listed, and say so in `checks_performed`.

## Sink tables

### Python / FastAPI (worked example)

Detect languages and frameworks from manifests and lockfiles and record, per sink category, the concrete APIs and their safe counterparts plus the framework's authentication and authorization idiom. Python/FastAPI, the worked example: `cursor.execute(f"...")`, `%` or `.format` into SQL, SQLAlchemy `text()`, `.from_statement`, identifier or sort-column interpolation; `subprocess` with `shell=True`, `os.system`, `os.popen`; `eval`, `exec`, `importlib.import_module(user)`; `pickle`, `marshal`, `yaml.load` or `unsafe_load`, `jsonpickle.decode`; `jinja2.Template(user)` or `autoescape=False`; `open()`, `FileResponse`, `os.path.join` with user segments; `requests`, `httpx`, `urllib` with a user-influenced URL (scheme and host allow-list, resolve-then-connect, `follow_redirects=False`, timeouts); `lxml` or `xml.etree` with entities; `re.compile(user)`; `logging` with raw user strings; `random` or `uuid4` for tokens; `hashlib.md5` or `sha1` for passwords; `verify=False`; `allow_origins=["*"]` with credentials; `debug=True`, `/docs` and `/openapi.json` reachable; `Depends` chains and router-level dependencies for auth. For any other stack derive the equivalent from ASVS V1, V5 and V15 and the OWASP cheat sheets before step 4. Do not rely on memory of a framework's defaults; open the installed package's source in the sandbox [R6].

### Other stacks

Derive the equivalent table from ASVS V1 (encoding and sanitization), V5 (validation and business logic) and V15 (secure coding) and the OWASP cheat sheets below before the generate phase: the query, command, code, template, deserializer, file-path, outbound-URL, XML, regex and log sinks; the framework's authentication and authorization idiom; its session and token handling; its defaults for CORS, debug surfaces and error pages. Open the installed package's source in the sandbox; never rely on memory of a framework's defaults.
